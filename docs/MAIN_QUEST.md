# 主线目标系统

本文档定义当前版本的主线目标、阶段判定、玩家提示和验收方式。主线系统的职责不是替代任务榜，而是把修炼、任务、采集、战斗、突破、宗门、洞府和州域推进串成一条始终可理解的成长路线。

## 1. 设计目标

主线目标必须回答玩家五个问题：

1. 我现在处于哪一章？
2. 下一步应该去哪里？
3. 到达后需要做什么？
4. 当前进度是多少？
5. 完成后会得到什么，并解锁什么？

当前实现使用现有 `GameState` 自动推导主线阶段，不新增存档字段。这样可直接兼容旧档，也避免“主线记录”与真实任务、境界、物品状态不一致。

## 4. 详细主线路线

### 4.1 第一章：初入仙途

#### 阶段 1：引气入体

- 地点：修炼页；
- 操作：点击聚气球；
- 进度：是否完成过至少一次聚气；
- 反馈：修为增加、日志更新、世界时间推进；
- 完成后：引导玩家前往青云城城北任务榜。

验收：

- 新档初始目标必须是该阶段；
- 完成一次聚气后立即切换到下一阶段；
- 页面刷新后阶段保持正确；
- 已达到炼气中期的旧档不显示该阶段。

#### 阶段 2：城北初领差事

- 地点：中州 → 青云城 → 城北任务榜；
- 操作：打开任务榜，接取《采集凝气草》；
- 进度来源：`world.tasks.collect_qi_grass.status`；
- 完成后：目标切换到灵药谷。

验收：

- 任务未接取时显示等待接取；
- 接取后无需额外按钮即可切换阶段；
- 已完成任务的旧档自动跳过。

#### 阶段 3：灵药谷采药

- 地点：中州 → 灵药谷 → 凝气草田；
- 操作：采集凝气草；
- 目标：凝气草 x2；
- 进度来源：`inventory.items.qi_grass`；
- 关联学习：地图移动、场景切换、采集、背包物品。

验收：

- 每次采集后进度实时更新；
- 达到 2 株后切换到交付阶段；
- 任务已经完成时自动跳过；
- 数量超过 2 时进度显示封顶，不超过 100%。

#### 阶段 4：交付凝气草

- 地点：中州 → 青云城 → 城北任务榜；
- 操作：点击《采集凝气草》的完成按钮；
- 完成条件：任务状态为 `completed`；
- 奖励：90 灵石、12 贡献、3 声望；
- 设计目的：完成“接取—前往—采集—交付—奖励”闭环。

验收：

- 材料不足不能完成；
- 完成后正确扣除 2 株凝气草；
- 奖励只结算一次；
- 主线切换到黑风讨伐。

### 4.2 第二章：山中试锋

#### 阶段 5：接取黑风讨伐

- 地点：青云城城北任务榜；
- 操作：接取《讨伐黑风山妖兽》；
- 完成条件：任务状态为 `accepted` 或 `completed`；
- 完成后：引导前往黑风山。

#### 阶段 6：黑风山试炼

- 地点：黑风山山狼巢穴或黑风营地；
- 操作：进入战斗并获胜；
- 目标：妖兽骨 x1；
- 进度来源：`inventory.items.beast_bone`；
- 设计目的：介绍小队回合制、技能、丹药、敌人行动与战斗掉落。

验收：

- 战斗期间主线卡隐藏，避免挤压战斗操作区；
- 战斗胜利并获得妖兽骨后进入下一阶段；
- 逃跑或失败不错误推进；
- 妖兽骨来源必须稳定，不能只依赖极低概率掉落。

#### 阶段 7：回城复命

- 地点：青云城城北任务榜；
- 操作：交付妖兽骨；
- 奖励：120 灵石、18 贡献、5 声望；
- 设计目的：完成“任务—战斗—掉落—交付”闭环。

验收：

- 没有妖兽骨时明确提示条件未完成；
- 完成后资源和任务状态一致；
- 主线进入首次突破阶段。

### 4.3 第三章：炼气进境

#### 阶段 8：突破炼气中期

- 地点：修炼页；
- 操作：聚气到炼气初期修为上限，并准备 80 灵石；
- 进度：当前境界修为 / 当前境界所需修为；
- 完成条件：境界达到 `qi_middle` 或更高；
- 设计目的：介绍突破成本、成功率、心境、伤势和失败惩罚。

验收：

- 修为未满时显示实际进度；
- 资源不足时突破面板说明缺口；
- 成功后切换到古修洞府目标；
- 失败后仍停留本阶段，并能够通过正常玩法恢复；
- 已高于炼气中期的旧档自动跳过。

### 4.4 第四章：古修遗泽

#### 阶段 9：寻得筑基丹

- 地点：中州 → 古修洞府 → 残阵守卫/残破丹室；
- 操作：挑战守卫、搜索丹室；
- 目标：筑基丹 x1；
- 完成条件：拥有筑基丹，或已经达到筑基初期；
- 设计目的：把秘境、Boss、关键突破材料和高价值奖励连起来。

验收：

- 目标明确说明筑基丹用途；
- 筑基丹存在可追踪来源；
- 后续需增加首次领取标记，避免唯一剧情机缘无限重复；
- 已达到筑基的旧档不会因已消耗筑基丹而回退到该阶段。

### 4.5 第五章：青云问道

#### 阶段 10：拜入青云宗

- 地点：青云城 → 城东大道；
- 操作：递交青云令牌；
- 完成条件：`world.sectJoined`；
- 解锁：宗门页、贡献/声望、宗门修炼加成；
- 设计目的：建立中长期身份成长。

验收：

- 未持有令牌时现有兼容逻辑仍可补录令牌并入宗；
- 入宗后宗门导航可用；
- 主线卡“下一解锁”随状态改变；
- 重复点击不重复给予奖励。

### 4.6 第六章：道基初成

#### 阶段 11：冲击筑基初期

- 地点：修炼页；
- 操作：完成炼气中期、后期、圆满，使用筑基丹冲击筑基；
- 进度：从炼气中期到筑基初期的累计修行路程；
- 完成条件：境界达到 `foundation_early`；
- 解锁：洞府、筑基属性和南疆进阶内容。

验收：

- 累计进度跨境界连续增长；
- 境界切换时进度不倒退；
- 达到筑基后进入南疆目标；
- 失败惩罚不造成无法继续的死档；
- 各阶段材料均有明确稳定来源。

### 4.7 第七章：南疆风云

#### 阶段 12：踏入南疆

- 地点：大世界 → 南疆 → 巫妖盟；
- 操作：点击南疆标记寻路并进入州域；
- 完成条件：当前州域为 `south_ridge`，或已存在南疆完成任务；
- 设计目的：把筑基玩家从中州引向新的资源生态。

验收：

- 目标文案说明推荐境界和风险；
- 到达南疆后立即切换到“立足南疆”；
- 已完成南疆内容但当前回到中州的旧档不会回退；
- 低境界玩家仍可自由进入，但必须看到危险提示。

#### 阶段 13：立足南疆

当前计入进度的任务：

- `collect_miasma_flower`：采瘴毒花；
- `purge_baicao_vines`：清剿妖藤；
- `patrol_beast_mountain`：巡查万妖山；
- `investigate_tide_cave`：探查潮音秘洞。

完成条件：

- 上述任意两项任务为 `completed`；或
- 境界达到筑基中期，视为旧档已越过该阶段。

设计目的：证明玩家已经建立至少两条南疆资源路线，而不是只进入地图即算完成。

验收：

- 每完成一项悬赏，进度从 0/2 更新到 1/2；
- 任意两项组合均可完成；
- 重复任务后续若开放，必须只按任务完成状态计算，不能重复累加同一项；
- 达到筑基中期的旧档自动完成；
- 完成后显示当前版本主线完成状态。

## 5. 下一解锁提示

目标卡根据已有系统状态显示最近的系统解锁：

| 条件 | 提示 |
| --- | --- |
| 尚未入宗 | 加入青云宗后开放宗门页与宗门修炼加成 |
| 已入宗但尚未开放灵宠 | 炼气圆满开放灵宠系统 |
| 已开放灵宠但尚未开放洞府 | 筑基初期开放洞府与闭关 |
| 已开放洞府但尚未开放同伴 | 筑基中期开放同伴编队 |
| 以上均开放 | 结丹境、炼丹、灵田与跨州主线 |

该提示只表达最近方向，不替代完整系统解锁说明。正式解锁时还需要独立弹窗或日志反馈。

## 6. 兼容策略

主线阶段采用“真实状态推导”，因此兼容规则如下：

- 已达到炼气中期的旧档跳过首次聚气、采药和黑风任务教学；
- 已达到筑基初期的旧档即使已消耗筑基丹，也跳过“寻得筑基丹”；
- 已完成南疆任务但当前身处中州的旧档仍视为进入过南疆；
- 达到筑基中期的旧档视为已经立足南疆；
- 主线卡不写入 `RootSave`，本次不提升存档版本；
- 后续正式剧情若需要不可逆选择，再新增独立剧情标记与迁移。

## 7. UI 规则

- 主线卡显示在顶部状态和当前功能模块之间；
- 战斗状态隐藏主线卡，优先保证战斗操作空间；
- 卡片包含章节、序号、标题、摘要、进度、地点、行动、收益和下一解锁；
- CTA 只负责切换到对应一级模块，不在本轮自动操控地图角色；
- 后续“追踪地点”应通过地图高亮和寻路确认实现，不能未经确认直接消耗移动时间；
- 进度条必须具备可访问的 `progressbar` 语义；
- 状态不能只靠颜色表达，完成状态同时显示文字标签；
- 小屏宽度下地点、行动和收益保持可读，不横向溢出。

## 8. 后续演进

当前主线是“状态推导 V1”。下一阶段应升级为配置化目标系统：

```ts
interface QuestObjective {
  id: string;
  type: "gather" | "kill" | "talk" | "visit" | "task" | "realm" | "equip" | "facility";
  targetId: string;
  amount: number;
}
```

然后逐步支持：

- 多目标任务；
- 任务前置与分支；
- 地图追踪和目标高亮；
- NPC 对话状态；
- 一次性剧情标记；
- 章节完成奖励；
- 日常/周常任务；
- 任务放弃、时限和失败；
- 主线事件回顾；
- 测试用阶段夹具。
