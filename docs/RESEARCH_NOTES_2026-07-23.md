# 文字 RPG 与修仙刷宝研究笔记

> 日期：2026-07-23
> 目的：为《问仙》的移动端文字修仙、格子历练、路途抉择、回合战斗和刷宝养成建立可验证的设计依据。本文只提炼机制，不复制作品文本、美术、专有设定或完整系统规模。

## 研究结论

《问仙》当前最值得强化的不是继续增加页签，而是让一次短历练同时产生三种决策：

1. **路线决策：** 目的地、路程、风险与途中异闻共同决定“走哪条路”。
2. **战斗决策：** 可读的敌我状态、防御、技能与撤退决定“是否继续冒险”。
3. **构筑决策：** 战后明确展示掉落，并立即与已穿装备比较，决定“如何变强”。

因此 v0.2.0 先完成“纯文字格子行路 → 路途异闻 → 战斗 → 统一掉落 → 结算 → 装备比较”的纵向闭环。地图视觉不依赖图片；内容密度来自文字、格子地形、位置关系、规则与后果。

## 转化为《问仙》的设计原则

### 1. 事件采用可组合的短单元

- 每条事件记录适用地图、地区、地点、最短路程、权重、冷却、选项成本、结果和标记。
- 每个事件至少提供一个无需资源的兜底选项，避免玩家因资源不足卡死在弹窗。
- 选择可以改变修为、灵石、物品、心境、时间和事件标记；后续事件通过标记回收因果。
- 事件文案要短而具体：场景、冲突、两个可判断的选择，以及明确但不完全剧透的结果预览。

### 2. 格子地图负责空间，文字负责想象

- 取消图片地图，保留 `48x32` 文字格、地点锚点、地形通行成本、角色位置和 A* 路径。
- 格子必须让玩家读出“我在哪里、要去哪里、路径多长、会经过什么地形”。
- 地图不追求写实绘制；世界感来自地点命名、道路关系、行程时间、异闻和抵达后的场景行动。

### 3. 掉落必须形成下一次决策

- 普通怪稳定提供材料，低概率掉基础装备；精英提高装备概率和品级；首领保证装备并承担关键材料与首通唯一奖励。
- 战后统一结算，装备可立即进入背包；详情用最终生效属性与当前同槽装备比较。
- 下一步优先实现装备出售/分解，让低价值装备有退出渠道，再讨论锻造、洗练或强化。

### 4. 失败有压力，但可恢复

- 战斗中的气血与灵力带回世界，逃离不重置消耗。
- 战败返回州域安全地点并保留最低恢复比例；不给奖励，但不删除角色、装备或关键任务物品。
- 采集、宝箱和事件使用冷却或一次性标记，防止无限点击破坏路线与战斗价值。

## 后续验证问题

- 路途异闻是否让一次跨地点移动比直接点“进入”更有记忆点？
- 玩家是否能在结算后 10 秒内判断新装备值得穿戴、保留或分解？
- 首领首通专属奖励是否明显改变下一场战斗，而不是只提高一小段战力？
- 纯文字格子地图在 360–430px 宽度上是否仍能看清角色、地点、路径与地形？
- 五行斗法应进入现有技能/灵力框架，还是成为独立资源层？在回答前不扩系统。
