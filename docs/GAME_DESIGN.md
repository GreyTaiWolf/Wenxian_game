# 游戏设计文档

本文档记录修仙文字 RPG 的长期设计方向。任何新增玩法、内容、地图、系统、解锁或叙事结构时，都必须同步更新本文档。

## 核心体验

玩家从青云镇外醒来，以散修身份开始修仙。早期目标是修炼聚气、积累资源、探索中州、加入青云宗、获得灵宠或同伴，并最终突破到筑基阶段。游戏以文字反馈、轻量地图和回合制战斗推进。

当前体验支柱：

- 修炼：通过聚气获得修为，满足境界要求后尝试突破。
- 突破：消耗灵石和材料，按成功率提升境界，并解锁新系统。
- 背包：记录材料、丹药、任务物品和装备展示。
- 历练：通过“大世界 -> 具体地点 / local map”的两层格子地图探索，触发对话、采集、战斗、任务、入宗和招募。
- 战斗：玩家和最多两名队友对抗妖兽或敌对修士，采用速度排序和回合行动。
- 宗门：加入青云宗后获得身份、贡献、声望和任务联系。
- 洞府：开局开放入口，承载闭关、聚灵阵、灵田和离线收益。
- 存档：本地三槽位存档，支持设置、继续、新建和删除。

## 当前世界内容

### 中州

中州是早期修行和新手内容中心。

- 青云镇：中州早期主镇，使用无网格镇景图进入内部场景；包含小小仙铺、赵家炼器铺、陈半仙秘籍摊、李百草草药铺、城主府、公告栏、青云客栈和客栈老板娘的灵田。
- 天玄城门：中州地图新城门场景，位于 `28,16`，使用竖版城门图展示天玄城正门、守门阵纹与左右两名可对话修士。
- 黑风山：野外战斗区，使用 local map 展示山道、黑灵泉、山狼巢穴、墨金洞、黑风营地和黑风妖寨；玩家从右上附近的山道进入，并只能沿显式山路前往各场景，战斗仍复用山狼和黑风妖修。
- 灵药谷：采集和战斗区，提供凝气草、灵草，并触发青羽狐事件。
- 古修洞府：秘境区，提供洞府守卫战斗和筑基丹、青木灵液等机缘。
- 落霞镇：任务叙事地点，用于送信任务和商路传闻。

### 南疆

南疆是当前开放的第二个州域，主题为巫妖盟、木灵宗、草木灵药、瘴气秘境与潮汐海市。南疆不硬锁低境界玩家进入，但通过推荐境界、敌人强度和危险提示表达风险。

- 巫妖盟：南疆主势力和盟城，包含巫妖盟城门、盟城坊市、巫妖盟悬赏碑、使者馆和巫祝石庭。
- 木灵宗：南疆大型宗门，第一版不允许加入，作为草木宗门地点、商店、采集、对话和试炼入口。
- 百草谷：灵药采集与妖藤战斗区，提供灵草、凝气草和妖丹碎片。
- 万妖山：妖兽战斗与灵宠踪迹地点，提供妖兽骨和妖丹碎片。
- 瘴雾沼泽：瘴毒花采集、蛊虫战斗和沉木机缘地点。
- 千瀑灵崖：秘境区，提供灵瀑守卫战斗和青木灵液机缘。
- 潮汐海市：海边坊市和潮汐传闻地点，售卖南疆材料。
- 归潮礁岛：潮音秘洞与沉珠宝匣秘境，提供潮生贝和灵石奖励。

### 未开放州域

以下州域已在大世界地图中预留，但暂未开放内部地点：

- 东海：万岛沧溟，未来方向为仙舟、海岛、水府、归墟遗迹。
- 西漠：沙海佛国，未来方向为魔宗、佛寺、商道和荒漠秘境。
- 北境：玄冰雪域，未来方向为剑修、冰修、雪原部族和寒域试炼。

新增州域时，应先补充州域主题、主要势力、资源类型、敌人生态和进入条件，再添加具体地点。

## 系统设计

### 修炼与境界

修炼是主成长线。玩家当前通过手动聚气获得修为，宗门状态提供倍率加成。境界突破负责推进版本阶段和系统解锁。

玩家等级采用“修仙境界等级”，不额外设置传统 `Lv.1 / Lv.2`。每个玩家等级由“大境界 + 小阶段”组成：大境界包括凡人、炼气、筑基、结丹、元婴、化神、炼虚、合体、大乘和飞升后预留；小阶段固定为初期、中期、后期、圆满。当前存档仍保存 `realmId`，但每个境界配置都必须标注 `majorRealmId` 与 `phaseId`，用于修为曲线、装备穿戴要求、区域掉落和敌人难度。

玩家属性采用“存档核心字段 + 运行时派生字段”。存档保存境界、修为、当前气血/灵力、年龄、寿元、心境、悟性、伤势、灵气不稳、灵石和基础战斗属性；境界名、修为上限、战力等显示值从配置和最终属性实时计算。旧存档中的 `power`、`lifespanCurrent/lifespanMax` 和文本心境只作为兼容来源，不再作为真实规则来源。

突破成功后直接套用目标境界基础属性，气血/灵力回满，寿元更新，心境提升并清空灵气不稳。突破失败按小境界和大境界区分惩罚：小境界以修为回落、心境下降和不稳层数为主；大境界额外增加伤势，体现资源门槛。

神识系统在装备 V1 中改为正式受限属性：代码字段统一为 `spiritSense`，元婴前玩家与装备神识默认为 0，元婴阶及以上装备才允许生成神识主属性和神识词条。治疗、回灵、法术命中与反闪避逻辑读取最终神识。

新增境界时必须说明：

- 境界定位和节奏目标。
- 所属大境界与小阶段。
- 修为需求和突破成本。
- 成功率及失败惩罚。
- 解锁的新系统、内容或地图。

### 物品、装备与双轴品级

物品采用双轴设计：器类阶位表示“这件东西属于哪个修仙大境界”，颜色品级表示“这件东西有多稀有、多少词条、视觉反馈有多强”。器类阶位必须压过颜色品级，避免低境界高颜色装备在主属性上压过高境界普通装备。

器类阶位：凡阶、炼气阶、筑基阶、结丹阶、元婴阶、化神阶、炼虚阶、合体阶、大乘阶和飞升后预留。装备、消耗品、材料、符箓和阵盘都可以拥有器类阶位；任务和剧情物品默认不参与普通掉落逻辑。

颜色品级采用 9 档：凡品、良品、精品、灵品、玄品、地品、天品、仙品、神品。颜色品级主要影响颜色、词条数量、可出现的最高词条品级、特殊效果概率、价格曲线和同阶内的属性浮动，不替代器类阶位。

装备词条也使用同一套九品级。装备品级只决定可出现的最高词条品级、词条数量和高阶保底；单条词条的强度、稀有度和功能定位由词条自身 `grade/role` 决定。低品词条可以出现在高品装备上，高品词条不能出现在低品装备上，例如灵品装备最多只生成凡品到灵品词条，不会出现玄品及以上词条。

当前开放规则：

- 每个正式物品配置一个器类阶位和一个当前颜色品级，例如炼气阶凡品回春散、炼气阶良品凝气草、筑基阶灵品筑基丹。
- 装备主属性 V1 改为“境界阶位 × 品级 × 部位换算”：武器读取境界/品级攻击表，其他部位按武器 W 值或专表派生。
- 同大境界内，小阶段影响装备投放：初期以白/绿为主，中期以绿/蓝为主，后期稳定出现蓝/紫，圆满开始投放紫以上、突破材料和 Boss 掉落。
- 紫色灵品以上开始偏用途装备和构筑价值，不做无脑上位替换。
- 装备词条实例固化词条品级和功能定位，详情与洗炼台在词条名前显示短标签，例如 `灵·回灵`；策划权重表不在前台展示。
- 装备栏、背包九宫格、物品详情、战斗丹药槽和法宝槽都读取物品品级展示对应 UI 特效。
- 旧测试存档中的旧六品后缀会按兼容映射折回正式物品 ID；旧 `mystic` 映射为新灵品。
- 装备采用单件实例系统：同名装备在背包中作为不同实例保存，实例固化 `name/displayName/realmTier/quality/slot/mainStats/affixes`，穿戴槽保存装备实例 ID。
- 旧装备实例读档时会按当前装备数值版本补齐词条 `grade/role`，剔除异常超过装备品级或槽位不合法的词条后稳定补 roll；本次词条品级化不提升 `RootSave` 顶层版本。
- 装备栏 V1 为 8 槽：武器、法袍、头冠、护腕、鞋履、戒指、护符和法宝；取消独立神识法宝栏，神识相关词条由法宝或护符承载。旧存档的头冠、鞋履、饰品、法宝槽会迁移到新槽位。

### 历练与地图

历练通过两层格子化地图组织：第一层是超大世界地图，第二层统一称为 local map。大世界地图直接显示青云镇、黑风山、灵药谷、天玄城、青云宗、万兽山、洞府、秘境、禁地和资源点等 POI；中州、南疆、东海、西漠、北境不再作为可进入的中间地图层，只保留为 `regionTag`、`climateTag` 和世界区域文字标签。玩家点击任意大世界 POI 后先自动寻路移动，抵达后打开地点预览卡，再由玩家确认进入对应地点的 local map。local map 用于城市、城镇、宗门、山脉、秘境、洞府等内部探索，继续承载对话、商店、任务榜、战斗、采集、招募、入宗和机缘。

地图表现采用统一 `GridMapPanel`：保留 `gridMaps`、`gridMapZones`、`gridNavigation`、A* 寻路、自检、玩家当前位置和移动路径逻辑；大世界地图起步尺寸为 `320x200`，支持后续扩展到 `512x320`；渲染必须按视口裁剪，只绘制当前屏幕附近格子，不能一次性渲染全部格子。`wild` 与 `secret` 内部地图只允许沿显式路径格移动，城市/城镇保留自由寻路。大世界不再依赖 `World_map.png`、`World_map_nanjiang2.png`、`World_map_zhonzhou2.png` 作为主要地图背景；地点内部的场景图、建筑图和剧情图继续保留。

大世界和所有 local map 顶部统一使用紧凑 HUD 标题栏：大世界标题为“问仙大世界”，副标题显示当前抵达或正在前往的 POI；local map 标题显示地点名，副标题显示“当前：某场景”或行路目标。普通玩家界面不常驻显示放大、缩小、重置、网格和自检按钮，缩放仍通过滚轮或触控手势保留，网格和自检只作为开发调试能力保留在代码或未来设置入口中。玩家可见 UI 文案统一称为“内部地图”，`local map` 只作为数据层和文档中的技术名使用。所有内部地图标题栏右侧都显示人物入口：城市/城镇显示“城镇人物”，山脉、秘境、洞府等非城镇显示“此地人物”，数量取当前地点固定 NPC 与游历 NPC 之和。城镇内不在地图下方常驻地点档案、场景列表、资源、敌人、掉落或 NPC 卡片，玩家通过地图移动与人物弹窗进入对话、商店和任务。内部地图标记只显示名称，不在标记下显示类型、身份、推荐、危险等详情；固定在场景/建筑里的 NPC 不直接显示为地图人物标记，点击地点后在“在某地点”弹窗中列出。点击内部地图上的游历角色或地点标记时，同样先自动寻路；点击角色抵达后打开人物弹窗，点击建筑/地点抵达后打开“在某地点”的地点弹窗。地点弹窗显示该地点内的修士和可用设施，商店、任务榜、打造、洗炼等正式功能优先由对应 NPC 或管事入口打开。

缩放信息层级：

- `0.4x-0.8x`：只显示大城、大宗门、大山脉、禁地、主线目标和玩家位置。
- `0.8x-1.5x`：显示城镇、山脉、道路和灵舟航线名称；移动端不常驻显示危险等级和推荐境界小字，这些信息优先放入地点信息抽屉，避免与玩家标记重叠。
- `1.5x-2.5x`：显示洞府、资源点、秘境、小型任务点和妖兽区。
- `2.5x-4x`：显示具体格子、地形、灵气浓度、移动消耗、可通行状态和路线格。

新增地图内容时必须说明：

- 玩法目的：资源产出、剧情推进、战斗挑战、系统解锁或氛围补充。
- 解锁条件：境界、宗门身份、任务状态、道具或未来剧情条件。
- 玩家收益：修为、灵石、材料、任务进度、队友、声望或系统入口。
- 关联系统：任务、战斗、背包、宗门、洞府或未来系统。

### NPC 与城镇人物

NPC 系统第一版服务青云镇，并使用 `src/data/npcs.ts` 作为统一配置入口。NPC 数据包含姓名、称号、性别、家族、势力、分组、常驻地点、店铺、任务、对话、互动按钮、初始境界、成长值和游历路线。青云镇首版人物包括清雨、苏达、赵铁匠、陈半仙、李百草、罗执事、云娘、顾青萝，以及韩牧野、林书雨、许千帆、白芷荷、莫小楼、唐砚、叶灵舟、沈晚晴等过路修士。

城镇人物弹窗按“常驻人物、店铺人物、任务人物、过路修士”分组。固定 NPC 不随时间移动，主要承担店铺、任务、场景和叙事入口；游历 NPC 记录当前位置、世界 POI、境界、成长值、上次更新时间、移动目标和任务种子，随着游戏时间推进在大世界 POI 间迁移并缓慢成长。

关系网采用显式关系表，第一版支持父母/家族、师徒、同门/势力、掌柜/伙计、好友、竞争、债务和传闻关联。关系先用于 NPC 名册和对话信息展示，后续可扩展为好感、支线、随机任务、结仇和同伴招募条件。

NPC 交互规则：

- 城镇人物名册不是远程对话列表。玩家点击人物后，应先在 local map 中前往该 NPC 所在场景；抵达场景后才自动打开 NPC 对话弹窗。如果 NPC 没有可定位场景，只给出行踪未定的日志反馈。
- NPC 对话使用居中 `GameDialog`，内容包含头像/姓名/身份/势力、当前位置、境界、关系标签、对话文本和互动按钮。
- 商店、任务榜和 NPC 随机任务统一使用居中 `GameDialog`，不嵌入地图面板或底部抽屉。
- 商店弹窗显示店名、掌柜、刷新周期、当前灵石、分类标签、商品格、价格、库存和售罄状态；手机宽度每页 8 格，宽屏每页 9 格。
- NPC 对话中的“购买”只负责打开对应商店弹窗；“任务”只负责打开任务榜或未来 NPC 随机任务弹窗；“打造”和“洗炼”进入对应地点服务弹窗。赵家炼器铺第一版由赵铁匠作为管事，提供交易、图纸研读、打造装备和洗炼词条。

### 战斗

战斗使用小队制回合机制。玩家、同伴、灵宠和敌人拥有气血、灵力、攻击、防御、神识、速度、闪避、暴击和暴击倍率等属性。战斗开始先进入 Round 0 准备回合，Round 0 不计入正式回合，只负责加载双方基础属性、装备、装备词条、法宝槽词条、同伴/灵宠词条、敌人模板词条，并按优先级结算开场禁用、破坏、封器、护盾、命灯、先手和法则类词条。准备完成后重新计算最终属性，生成第 1 回合行动顺序，正式战斗从 Round 1 开始。
正式战斗最多 35 个回合。每个正式回合开始都会重新生成速度顺序，速度高者先行动；同速时玩家优先，其次按品级/先手权重，仍相同则随机。第 15 回合起进入战意升温，双方造成伤害提高，此后每 3 回合继续升温，避免战斗拖到上限。若第 35 回合完整行动后仍未分胜负，普通战斗脱战无奖励，精英和 Boss 战挑战失败无奖励；特殊生存战可配置为坚持到上限胜利。
战斗操作区采用轻量携带栏：第一排显示两个武技槽，第二排显示两个功法槽，第三排显示神通、法宝和丹药。法宝槽读取 `artifact` 装备，拥有主动、开场守护或法则词条时可催动，否则展示被动生效状态。所有特殊效果统一归入词条系统，旧 `domain_*` 仅作为兼容词条 ID 保留，不再把“领域系统”作为独立玩法概念。
战斗是历练地图的临时覆盖态。进入战斗时底部模块应保持在“历练”，并记录战前州域、地点、场景、地图层与坐标；胜利或成功逃离后清除战斗并按该上下文返回当前大世界 / local map 位置。战败才回到最近城镇入口，入口必须取地点配置中的有效场景，不允许回到不存在的旧场景 ID。
战斗站位固定为我方在左、敌方在右；移动端窄屏也保持双列，只压缩角色卡信息密度，避免敌我顺序在不同屏宽下改变。

普攻是基础行动，没有可用技能或灵力不足时会自动兜底；若角色处于“禁普攻 x 次行动”，则不能使用普攻，仍可使用未被禁用且灵力足够的技能。禁普攻且无可用行动时，角色会改为防御或调息。连击和群攻都只能由主普攻触发，技能、群攻和连击追加攻击不会再次触发连击或群攻，每次行动最多触发一次连击。

当前战斗定位：

- 炼气前期：山狼和守草妖兽提供基础战斗教学。
- 炼气中后期：黑风妖修混合修士和妖兽，测试队伍续航。
- 筑基前后：古修洞府守卫作为更高压力战斗。

### 宗门

青云宗是早期组织线。当前功能包括入宗、身份展示、贡献、声望和任务列表。未来可扩展藏经阁、贡献兑换、师门关系、宗门战和宗门职位。

新增宗门玩法时必须说明：

- 贡献和声望的获得与消耗。
- 与境界、地图和任务的关系。

### 洞府

洞府是开局可进入的长期养成系统，不再受境界限制。当前洞府采用“大厅 + 功能按钮 + 子页面”结构，已开放修炼室、本府灵田、炼丹房、炼器室、灵兽栏和坐骑苑：玩家可闭关领取修为，升级聚灵阵提高闭关效率；灵田以前台单页 3x3 九宫格呈现，点击地块打开详情弹窗，空田可从背包式灵种栏选择种植，已种植地块可查看年份、成熟状态、收获或拔除；炼丹房通过丹方和丹炉炼制回春散、聚气丹、筑基丹；炼器室复用炼器铺的图纸打造与洗炼规则，并拥有洞府内升级；灵兽栏管理灵宠、喂养、进阶和设置出战；坐骑苑驯养坐骑并降低大世界与 local map 行路耗时。

灵田地块本身拥有独立灵土品级，品级影响该格成长速度但不限制可种种子品级。九宫格外层边框表现灵土品级；已种植时，灵植/种子品级使用约 80% 尺寸的内层品级框展示，避免灵土品级和灵植品级挤在同一层视觉里。

新增洞府玩法时必须说明：

- 收益上限和结算周期。
- 升级消耗、解锁条件和对修炼速度的影响。
- 是否影响存档结构，以及旧存档如何补默认洞府数据。

### 队友与灵宠

当前队伍最多包含两名成员，已有青羽狐和顾青萝。灵宠由洞府灵兽栏管理，玩家选择一只灵宠出战后同步进入队伍；灵宠偏护主和敏捷，伙伴偏治疗和术法辅助。

- 伙伴剧情、好感度、技能学习和队伍定位。
- 队伍容量、站位或战斗策略的进一步设计。

### 视觉与 UI 方向

当前 UI 方向调整为现代玄幻 App：保留修仙题材识别，但减少传统水墨、毛笔、卷轴和纸感表达。界面应更接近暗色手游 HUD，使用深色石墨底、半透明面板、细描边、柔和灵光和紧凑信息层级。

长期规则：

- 主色用于修炼、当前状态和可点击高亮；灵力、神通、奖励、危险等状态使用稳定语义色区分。
- 底部导航、顶部状态、背包装备、战斗槽位、地图标记、宗门与洞府入口优先配合轻量图标增强识别。
- 通用图标使用 `lucide-react`，业务组件通过 `src/components/GameIcon.tsx` 的语义名引用。
- 修仙专属图标，如灵石、丹炉、境界印记、灵宠、宗门令牌和秘境入口，可后续用本地 SVG 或图片补足。
- UI 样式改动若改变交互规则、信息层级或长期视觉规范，需要同步记录在本文档；纯色值微调且不影响规则时可不记录。
- 修炼页的主要成长反馈集中在圆形聚气按钮内，修为进度以球形波浪液面填充展示，独立境界进度条不再常驻。
- 修为进度满后，圆形聚气按钮文字改为“突破”；若下一境界需要灵石或材料，点击后弹出突破准备面板，固定显示 5 个材料格，空格只允许放入当前突破配置所需且玩家已拥有的材料堆叠。
- 品级视觉 V2.2 采用“暗色 HUD 底 + 品级纯色材质 + 阶梯式高阶特效”：物品格主体使用对应品级纯色侵染，不再铺满斜线、条纹或符纹；背包和装备格不显示额外小品级胶囊，品级主要由整格纯色材质、加粗边框、内辉光和名称字重表达。凡/良/精品以静态纯色底和轻边框为主，灵/玄品开始使用边框扫光和图标辉光；地品是红色地脉框，天品升级为红金/金色天光，仙品升级为蓝白/白金仙气，神品使用赤金核心、多层边框和短粒子感。所有高品级名称使用粗字重、短距离深色阴影和小范围锐利辉光，不再使用大面积红色描边或模糊光晕。背包格、装备槽、装备词条、品级徽章、战斗携带槽、奖励/装备 Toast 和详情浮层必须复用同一套品级 class，避免组件各自定义稀有度表现。
- 品级特效允许“全特效拉满”，但必须保持手机端可读：高品级可以使用边框、内发光、底纹、角标、扫光、短脉冲和点击扩散；地品以上的可交互装备格在点击/聚焦时出现短促扩散光。神品装备名称要更粗、更偏赤金红，并保留轻微闪光；不使用整块纯色盖住文字，不用常驻大面积模糊；`motion-off` 时保留静态颜色、边框和底纹，关闭扫光、脉冲、旋转和粒子感动画。
- 物品详情浮层只展示玩家决策需要的信息：名称、品级徽章、描述、阶位、类型、数量、核心属性、战斗效果、真实词条、价值和出售；配置曲线、颜色倍率、词条数量上限等策划调参信息不在前台展示。没有实际词条时不显示词条区。装备可用时不额外显示穿戴阶段，境界不足时只在底部主操作按钮提示。
- 装备词条按词条自身品级显示特效：背包装备详情和洗炼台的单条词条都复用 `grade-card / grade-chip / grade-name`，锁定和不可锁状态只叠加操作状态，不覆盖词条品级色、辉光和 `motion-off` 静态表现。
- 背包各分类统一使用 3 列 x 3 行凹槽格子，每页 9 格。装备分类中部标题为“背包”，只显示装备实例，格子内不显示数量；物品、丹药、材料继续显示堆叠数量角标。点击已占格子打开详情，空格只作为占位。
- 已穿装备格只显示部位和装备名，不在格子内展示属性加成或卸下按钮；点击已穿装备后复用装备详情浮层，底部操作为“卸下”和“返回”。
- 有角色热点的场景图应完整展示图片，并在角色附近叠加可点击姓名标记；点击后以居中弹窗展示 NPC 名称、身份和对话文本。
- 场景图中的 NPC 名字标记优先使用纯文字热点，不额外套按钮底板；点击后打开磨砂半透明 NPC 对话弹窗。NPC 对话弹窗可配置互动按钮，例如聊天、切磋、购买、任务或赠礼；首版先显示对话反馈和功能方向，后续再接入问答和切磋战斗。
- NPC 对话中的“购买”按钮不在原对话框内直接展示商品；点击后应关闭当前 NPC 对话框，并打开更大的商铺弹窗。商铺弹窗使用背包式商品格，分类为全部、丹药、法器、材料和杂货；手机宽度每页 8 格，宽屏每页 9 格，点击货物后在弹窗底部显示详情和购买按钮。
- 商铺库存按配置刷新，常用周期为每月或每季；购买会记录在当前刷新周期内，库存售罄后必须等待下次补货。地点面板不再常驻内联商店，正式入口优先走 NPC 或场景动作打开居中商店弹窗。
- 炼器铺打造台采用三段式工坊：图纸槽、材料槽、产物预览。未学配方时必须持有并研读图纸，研读会消耗图纸并永久写入存档；之后打造只消耗灵石和材料。洗炼台先选择背包装备或已穿装备，再打开居中操作台，支持锁定词条、一键放入材料和洗炼特效。
- 地点内部图片场景仍可使用整张背景图作为可拖拽、可缩放的场景图；场景图默认不显示网格，可点“网格”显示 `42x23` 坐标方块用于后续标注，不可走区域可用红色格标出。场景图上下方向锁定，横向拖拽和缩放时不得让图片离开 UI 框架。地点入口只显示文字和下方黄点，黄点表示实际落点；无独立场景图的入口点击后在图内抽屉展示详情，有独立场景图的入口进入更细的图片场景。
- 大世界和 local map 的 POI / 场景标记在缩放时保持稳定视觉尺寸，坐标跟随地图移动，但按钮本身不随地图放大遮挡视野。
- 大世界标记以 POI 为核心，文字位置取自 `worldPois` 与 `gridMapZones` 的 `anchor`，相邻标记可配置轻微像素偏移避免遮挡；中州、南疆、东海、西漠、北境只作为区域标签和气候标签显示，不再弹出可进入的州域地图。
