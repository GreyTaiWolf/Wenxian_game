# 策划数值文档

本文档记录当前版本的数值基线、公式和调参记录。任何修改境界、属性、技能、敌人、奖励、成本、概率、掉落或商店价格时，都必须同步更新本文档。

## 数值原则

- 早期成长应稳定、短反馈，玩家每次聚气或战斗都能看到收益。
- 突破成本用于引导玩家探索不同玩法，不应只依赖重复聚气。
- 新资源必须有明确来源和用途，避免只产出不消耗。
- 战斗难度应按区域和境界递进，避免普通野外战斗超过同阶段玩家承受能力。
- 关键数值优先放在 `src/data` 或 `src/game`，不要散落在 UI 组件中。

战力实时派生，不再保存为真实数值：

```ts
rawStatScore =
  maxHp * 0.10 +
  maxSpirit * 0.15 +
  attack * 1.80 +
  defense * 1.60 +
  speed * 1.20 +
  90 * critRate * critDamage +
  120 * dodgeRate +
  1.20 * spiritSense;

power = Math.round(rawStatScore * realmCoef[majorRealm] * stageCoef[phase]);
```

闪避在装备 V1 中正式启用，最终闪避率硬上限为 35%。神识字段统一为 `spiritSense`，元婴前装备不会生成神识主属性或词条。

突破成功改为套用目标境界基础属性：`hp/spirit` 回满，寿元更新，心境 `+5`，清空灵气不稳层数。

突破成功率：

```ts
breakRatePct = clamp(
  baseRate +
  (mindValue - 50) * 0.35 +
  (comprehension - 10) * 1.20 -
  injuryStacks * 3 -
  instabilityStacks * 4 -
  agePenalty,
  5,
  95
);

agePenalty = Math.max(0, age / lifespan - 0.80) * 25;
```

突破失败：

- 小境界失败：扣除突破成本；修为回落到当前上限 `88%`；气血/灵力降至 `60%`；心境 `-6`；灵气不稳 `+1`。
- 大境界失败：扣除突破成本与关键丹药；修为回落到当前上限 `75%`；气血/灵力降至 `30%`；心境 `-12`；灵气不稳 `+2`；伤势 `+1`。

## 战斗公式

来源：`src/game/combatEngine.ts`

- 战斗阶段：进入战斗后先结算 Round 0 准备回合，加载基础属性、装备、装备词条、法宝槽词条、同伴/灵宠词条和敌人模板词条；Round 0 不计入正式回合。准备完成后重新计算最终属性并生成第 1 回合行动顺序。
- 回合上限：正式战斗最多 `35` 回合。第 35 回合完整行动后仍未结束时，普通战斗脱战无奖励，精英/Boss 战失败无奖励，特殊生存战可配置为超时胜利并发放奖励。
- 行动顺序：每个正式回合开始重新生成顺序；所有存活单位按速度从高到低排序，先机和借势等临时速度提高会参与排序。速度相同时玩家优先，其次按品级/先手权重，仍相同则随机。
- 准备回合词条优先级：抗性 -> 禁止类 -> 破坏类 -> 装备封禁 -> 重新计算属性 -> 属性加成 -> 百分比属性 -> 全队被动 -> 开场护盾 -> 复活标记 -> 先手/速度 -> 第 1 回合行动顺序。
- 装备封禁：默认持续 `2` 个正式回合。封禁装备的主属性和词条全部失效，封禁法宝槽时法宝相关主动、护盾、命灯和减伤词条也失效；实现必须通过排除封禁槽位后重新计算最终属性，不做属性减法。
- 基础伤害：`floor(攻击 * 技能威力 - 目标防御 * 防御系数)`，最低为 `1`。
- 普攻和撕咬防御系数：`0.45`。
- 其他伤害技能防御系数：`0.35`。
- 战意升温：第 `15` 回合开始双方造成伤害 `+5%`，之后每 `3` 回合再 `+5%`，最高 `+40%`；只影响伤害，不影响治疗和护盾。
- 闪避：普攻、撕咬、扑击和引气斩吃完整闪避；飞叶术吃 50% 闪避；兽吼等范围伤害不可闪避。最终闪避软上限 30%，硬上限 35%。
- 暴击：命中暴击率时，伤害乘以角色自身暴击倍率，当前基础为 `1.50`；暴击率软上限 35%、硬上限 50%，暴伤普通上限 2.20，仙/神专属可到 2.50。
- 防御状态：受到伤害乘以 `0.5`。
- 护主减伤：受到伤害乘以 `0.65`。
- 攻击下降：攻击乘以 `0.85`。
- 回春诀治疗：`max(12, floor(28 + spiritSense * 0.6))`。
- 回灵效果：`max(5, floor(10 + spiritSense * 0.3))`；装备回灵词条可在回合开始额外恢复灵力。
- 逃跑基础成功率：`72%`，遁走词条可提高，上限 95%。
- 玩家战斗携带容量：`2` 个武技槽、`2` 个功法槽、`1` 个神通槽、`1` 个法宝槽、`1` 个丹药槽。
- 功法槽当前仅作为 UI 预留，暂不产生主动战斗效果。
- 法宝槽读取 `artifact` 装备；存在主动、开场守护或法则词条时可催动，否则展示被动词条状态。旧 `domain_*` 只作为兼容词条 ID，不再作为独立领域系统。
- 普攻不占用携带槽，也不在 UI 中显示；无可用携带行动时可作为随机敌方单体的兜底动作。`basicAttackDisabledActions > 0` 时禁用普攻，每次该角色行动后减 `1`；若禁普攻且无可用技能、丹药或法宝，则执行防御/调息。
- 连击：只能由主普攻触发，技能、群攻和连击追加攻击都不能触发连击；每次行动最多触发 `1` 次。
- 群攻：只能由主普攻触发，连击不能触发群攻，群攻不能再次触发群攻；群攻伤害可触发灼烧、雷击等元素词条，但触发率降低，不触发法则类词条。
- 攻击命中后的词条顺序：命中/闪避 -> 暴击 -> 破甲 -> 基础伤害 -> 护盾吸收 -> 气血扣除 -> 灼烧/雷击 -> 禁普攻/禁技能 -> 群攻 -> 连击 -> 斩杀 -> 死亡判定 -> 复活判定 -> 战斗结束判定。

### 装备词条品级规则

词条自身也使用九品级，装备品级是硬上限：`qualityRank[affix.grade] <= qualityRank[equipment.quality]`。低品词条可混入高品装备，高品词条不能出现在低品装备上；灵品装备最多出现凡品到灵品词条，玄品装备最多出现凡品到玄品词条。抽取权重倾向同品和低一品，避免高品装备被大量低阶词条污染。洗炼锁定词条保留原词条品级，重掷词条仍受装备品级上限约束。

副词条数值口径：普通数值词条读取境界基础范围后乘 `qualityGrades[affix.grade].affixCoeff`；带独立 `valueRange` 的机制词条视为该词条品级下的最终范围，不再乘装备品级系数，避免复活率、连击率等概率被高品装备二次放大。

- 改动项：`wild` 与 `secret` local map 改为只允许沿显式路径和场景锚点移动；黑风山入口改为山道，山道坐标为 `28,7`，黑风山场景路径采用主线分支。

- 新值：野外/秘境普通格默认不可走，路径格与场景锚点可走；黑风山路径为山道连接黑灵泉、山狼巢穴、黑风营地，黑灵泉/山狼巢穴通往墨金洞，黑风营地通往黑风妖寨，每个地点连接数不超过 3。

## 2026-05-28：道路优先寻路代价

- 改动项：A* 寻路新增独立路径代价函数，让已录入道路在路线规划中明显优先，但移动耗时仍沿用 `getGridMoveHours(cellDistance, movementCost)`，不改变当前行走时间、年龄推进、奖励、掉落或战斗数值。
- 旧值：寻路直接复用格子的 `movementCost`，道路格与普通平原的路径偏好差距不明显。
- 新值：道路格代价 `0.55`；城市、宗门和 POI 格代价 `0.75`；平原 `1.15`；山谷 `1.35`；森林 `1.65`；山地、沙漠、雪地 `1.85`；洞府和秘境 `2.15`；水域 `2.45`；瘴沼 `2.70`；禁地 `3.20`。
- 原因：玩家点击远处 POI 时，路径应优先贴近已录入道路、商路和灵舟航线，但不能为了走路网绕超长远路。
- 影响范围：只影响 A* 选路倾向和路线显示；不改变真实移动耗时公式、格子距离、角色境界、坐骑/法器/传送阵预留公式、敌人强度、奖励或商店价格。
- 验证方式：`npm test` 覆盖典型路线道路占比，`yarn build` 覆盖 TypeScript 与生产构建。
